Notes on origin
---------------

Two files with non-standard / unclear licensing that used to ship in this
project (krsobjp/js/deprecated/picker.js and
krsobjp/js/plugins/twosidedmultiselect/jquery.twosidedmultiselect.js) have
been removed from this repository. If that functionality is needed again,
replace them with an actively maintained, clearly-licensed alternative.

This list was compiled by inspecting the license header (or accompanying
README/LICENSE file) of each bundled component as of this repository
snapshot. If you add, update or remove a bundled library, please keep this
file in sync.
